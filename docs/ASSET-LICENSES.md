# Asset licences

Every third-party asset in this game is CC0 1.0 (public domain dedication). No attribution is required, and these credits are given anyway.
Everything else (sculpted dinosaurs, cave, terrain, trees, baked skin maps) is generated by the code in `tools/`. A few small effects, such as drips and the heartbeat, are synthesised at runtime.
